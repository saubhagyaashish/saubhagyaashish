## Selected projects

### [Shop Honest](https://github.com/saubhagyaashish/shop-honest)
AI agents that walk through an online shopping journey, collect evidence of dark patterns, propose fixes, and re-audit a corrected copy.

- Combines browser automation, measured checks, and AI review to produce findings with screenshot evidence.
- Includes a React dashboard, a FastAPI backend, and agents built with Google's Agent Development Kit.
- Built with Team Zero Context for the Google Cloud AI Builder Cup 2026.

**Stack:** TypeScript · React · Python · FastAPI · Playwright · Gemini · Google Cloud

[Try the app](https://shop-honest-ai.web.app) · [Watch the demo](https://www.youtube.com/watch?v=_mG4SobZ9E0) · [Architecture](https://github.com/saubhagyaashish/shop-honest/blob/main/docs/ARCHITECTURE.md)

### [Jarvis](https://github.com/saubhagyaashish/jarvis)
A personal AI assistant with text and voice conversations, persistent memory, tasks, reminders, and scheduled morning briefings.

- Pairs a React interface and animated 3D avatar with an agent running on Cloudflare.
- Uses Durable Objects for per-user state and Workflows for scheduled briefings.
- Connects external APIs and MCP servers, with approval for calls that change data.

**Stack:** TypeScript · React · Cloudflare Agents SDK · Durable Objects · Workers AI · three.js

[Try the app](https://jarvis.hiteacher.workers.dev) · [Architecture and setup](https://github.com/saubhagyaashish/jarvis#architecture)
